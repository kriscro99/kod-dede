# Kod Dede Grill — web stranica

Jednostranična prezentacijska stranica za **Kod Dede Grill**, restoran s roštiljem u Prečkom (Prečko 5C, Zagreb).

- Uživo: https://kriscro99.github.io/kod-dede/
- Sadržaj, fotografije i jelovnik preuzeti s https://koddede.com.hr/hr/ (bez cijena)
- Čisti HTML/CSS/JS, bez build koraka: `index.html`, `css/style.css`, `js/main.js`, `img/`

Stranica ima `noindex` (postojeća službena stranica ostaje glavna u Googleu). Kad ova postane službena, u `index.html` zamijeni `noindex, follow` s `index, follow`.
